# Portfolio | Mahek Kadam

Personal portfolio website showcasing my projects, skills, and achievements as a final-year Computer Engineering student focused on applied AI and data.

**Live site:https://mahekkadam.netlify.app/

---

## Sections

- **Home:** short intro and animated role headline
- **Skills:** programming, AI frameworks, backend and databases, design tools
- **Projects:** featured AI projects with tech stacks
- **Journey:** hackathon finalist placement, leadership role, and competition win
- **Contact:** email and social links

## Built with

- HTML, CSS, and vanilla JavaScript (no frameworks)
- Google Fonts (Outfit) and Font Awesome icons
- Features: typing effect, 3D tilt cards, scroll-reveal animations, custom cursor, responsive layout

## Run locally

```bash
git clone https://github.com/kadammahek/portfolio.git
cd portfolio
```

Open `index.html` in your browser. There's no build step.

## Deployment

Deployed as a static site on Netlify. The `netlify.toml` publishes the repo root directly, so no build command is needed.
